**আমার বগুড়া (Amar Bogura)** হলো বগুড়া জেলার ১২টি উপজেলা, ইউনিয়ন, পৌরসভা, স্বাস্থ্যসেবা, পর্যটন এবং নাগরিক কমিউনিটির জন্য নির্মিত একটি আধুনিক, দ্রুতগতির ও দ্বিভাষিক (বাংলা ও ইংরেজি) ডিজিটাল প্ল্যাটফর্ম।

প্রকল্পটি **Next.js (App Router)**, **NestJS modular architecture**, **Supabase (PostgreSQL)** এবং **Vite** সমর্থন সহ **Vercel Free Hosting**-এ সম্পূর্ণ বিনামূল্যে ডিপ্লয় করার জন্য প্রস্তুত।

## 🗄️ Supabase ডাটাবেস সেটআপ

প্রজেক্টে সম্পূর্ণ SQL স্কিমা ফাইল তৈরি করা আছে: `supabase/schema.sql`।

1. আপনার [Supabase Dashboard](https://supabase.com/dashboard)-এ যান।
2. বাম পাশের মেনু থেকে **SQL Editor**-এ ক্লিক করুন।
3. **"New Query"** খুলুন এবং `supabase/schema.sql` ফাইলের সব কোড পেস্ট করে **"Run"** চাপুন।
4. এটি স্বয়ংক্রিয়ভাবে তৈরি করবে:
   - `upazilas` টেবিল
   - `hospitals` টেবিল
   - `emergency_contacts` টেবিল
   - `tourist_spots` টেবিল
   - `community_posts` টেবিল (Row Level Security ও পাবলিক ইনসার্ট পলিসি সহ)
   - প্রাথমিক সিড ডাটা (রক্তদাতা, টিউশন, বাসা ভাড়া ইত্যাদি)

> 💡 **নোট:** Supabase সংযোগ না থাকলেও বা সাময়িক অফলাইনে থাকলেও সাইটটি ক্র্যাশ করবে না — এতে বিল্ট-ইন ফলব্যাক ডেটাস্টোর রয়েছে যা সব তথ্য প্রদর্শন করে।

## Local PostgreSQL (development)

Develop against a local database first, then point the same schema at Supabase.

1. Put this in `.env.local` (git-ignored; adjust user/password):
   `LOCAL_DATABASE_URL=postgresql://postgres:postgres@localhost:5432/amar_bogura`
2. `npm run db:setup` creates the database and applies, in order: `supabase/schema.sql`,
   `supabase/seed.sql`, `supabase/migrations/*.sql`, then loads the sample community posts and
   explore spots from `amr-bogura-data/`. It is idempotent; `npm run db:reset` rebuilds from scratch.
3. `npm run dev` - the app now uses local Postgres (it ignores the Supabase keys while
   `LOCAL_DATABASE_URL` is set). Public reads run as the `anon` role and writes/moderation as
   `service_role`, so Row Level Security behaves like production.

The setup script refuses to run against any non-local host, and local mode is disabled when
`NODE_ENV=production`.
